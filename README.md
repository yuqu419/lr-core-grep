## 实现思路
主要分为两个步骤：**解析参数**和**在文件中查找pattern**
### 解析参数
解析参数功能在parse.c文件中实现
我将解析分别分为处理pattern，处理选项，处理文件名，并分别存储起来，留到查找步骤使用
如果在每个步骤中遇到错误，会修改退出码和相应文件名，回到main函数进行错误处理
### 文件中查找
查找功能在search.c文件中实现
文件中查找以此分割为当个文件查找，单行查找，
## 构建与测试
- 使用**make**进行构建
```make
make
```

构建成功后，将在根目录下生成`lrg`可执行文件

- 使用**make clean**清理构建产物
```make
make clean
```
