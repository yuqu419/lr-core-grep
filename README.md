## 实现思路
主要分为四个步骤：**解析参数**、**搜索收集**，**格式整理**和**打印输出**

## 解析参数 
实现在`parse.c`中，主要函数为`parse_args`，作用为解析参数，得到`files`,`pattern`和`option`.


## 搜索收集
根据解析的参数打开文件，将匹配到的段存储到*match_line*中，在搜索阶段不会判断option，而是获取后续格式整理所需要的所有信息。
`match_line`维护三个成员变量
- m_string: 存储匹配到的段的字符串（m_string维护一个动态字符串）
- size_t: 记录匹配到的行号
- bool: 记录此行是否为忽略大小写匹配到的
